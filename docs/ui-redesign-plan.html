03 · 视觉系统

晨雾玻璃的规则

从参考图拿的是做法，不是照搬：浅雾底上铺三团静止的柔光色场，卡片是半透明磨砂玻璃，数字用细字重大字号，状态全部用胶囊表达。

材质分两种

  • 玻璃：白 62% 透明 + 22px 模糊 + 1px 白描边，用于导航、仪表卡、侧板、抽屉。
  • 纸面：实心白，用于题干、选项、解析、数据表格，保证正文对比度。
  • 不支持 backdrop-filter 或系统开启"减少透明度"时退回 92% 不透明白。

字与数

  • 仍用系统中文字体，不引入外部字体（服务部署在公网也不依赖 CDN）。
  • 大数字 28–32px、常规字重、等宽数字；单位和对比说明 12px 灰字。
  • 题干 18px / 1.85 行高不变。

形状与间距

  • 卡片圆角 20px，按钮、标签、导航全部用胶囊形。
  • 12 栏网格，卡片间距 14px；内容最宽 1440px。
  • 阴影只有一层，很淡，靠模糊和描边区分层次。

图表

  • 自己写一个小的 charts.js，用内联 SVG 画柱状、折线、半环、日历热力，不引图表库。
  • 每个 KPI 卡固定结构：标题 / 大数字 / 涨跌胶囊 / 对比说明 / 14 天微图。
  • 色场不做动画；交互反馈 160ms，尊重减少动效设置。
04 · 页面与分区

每个页面怎么改

页面新的分区和现在比
导航外壳顶部悬浮胶囊：标志 · 学习中心 / 题库 / 错题收藏 / 统计 / 管理▾（仅管理员）· 搜索 · 主题 · 头像菜单。手机端底部 4 栏标签。去掉 224px 侧栏和面包屑，内容区多出约 260px。
学习中心问候 + 考试倒计时 + 快捷胶囊；继续练习、本周打卡、科目掌握；4 张 KPI 卡；今日清单、真题进度、最近练习。专项配置器移入"自选专项"抽屉；数字都配上微图和昨日对比。
自选专项抽屉右侧滑出：科目多选卡片（带题量与掌握度）→ 小类胶囊 → 模式分段控件 → 题量 → 开始。逻辑与现在完全一致，学习中心、题库、错题页都能打开。
答题页细进度胶囊替代全局导航；左侧纸面题卡，右侧玻璃答题卡 + 笔记/同考点分段。收藏挪到题目右上角。快捷键说明收进 ? 浮层。判分、保存、考试交卷流程不改。
题库顶部"按题目 / 按试卷"分段；搜索胶囊 + 3 个常用筛选，其余进"更多筛选"弹层；结果是纸面表格，行内显示掌握状态胶囊。真题列表并入"按试卷"。筛选仍写入网址，可返回恢复。
错题收藏上方按科目分组的错题数卡片（点击即筛选），下方列表；一键"把这些错题组成练习"。新增按科目的错题分布。
统计日/周/月分段 + 一个"筛选"按钮；KPI 卡带上一周期对比；作答趋势（柱+正确率线）；26 周学习日历热力；模块正确率横条；对错分布半环。7 个下拉收进筛选弹层；新增对比和热力日历。
登录注册整屏柔光色场上一张居中的玻璃卡，左侧一句产品说明。最能体现新风格的一页，改动小。
数据 / 用户管理玻璃外壳 + 纸面表格；用户行带头像首字、角色胶囊、状态胶囊；邀请码做成可复制的卡片。功能不变。
05 · 后端配合

需要新增或调整的接口

判分、会话、导入导出、权限都不动。新增的都是只读汇总和一张设置表。

新增GET /api/dashboard

学习中心一次请求拿全：今日与昨日的题量、正确率、用时；近 14 天每日序列；连续打卡天数与本周打卡日；各科正确率与覆盖；待复习错题按科目计数；今日清单完成度。全部按北京时间自然日，复用现有 statistics 的计数口径（未交卷考试不计）。

新增用户设置

新表 user_settings（考试日期、每日目标题量、主攻科目），接口 GET/POST /api/me/settings。倒计时、今日目标、"主攻科目"默认勾选都从这里来。头像菜单里可改。

调整GET /api/stats

增加 compare=1：返回上一个等长周期的汇总，用于涨跌胶囊；增加 heatmap=1：返回近 26 周每日题量，用于学习日历。

调整GET /api/meta

试卷已有 done，再加每套试卷的正确率，供"真题进度"表使用。错题数增加按科目分组。

06 · 前端重构

代码层面的做法

  • 继续用原生 ES 模块，不加构建步骤。
  • 2,676 行的 style.css 拆成 tokens.css（颜色、圆角、阴影、字号）/ base.css / components.css（玻璃卡、胶囊、分段控件、抽屉、表格、KPI 卡）/ 每页一个小文件。
  • 新增 charts.js（柱、线、半环、热力）和 components.js（kpiCard()、pill()、segmented()、drawer()），各页面改为组合这些部件。
  • index.html 的侧栏改为顶部导航和手机底部标签；app.js 的路由与权限判断不变。
  • 沿用现有验收：隔离数据库 + ui_smoke.mjs，在 1440 / 1024 / 768 / 390 / 320 宽度截图检查；Python 测试为新接口补用例。
