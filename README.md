# 知序 · 金融监管备考工作台

独立项目：`D:\project\finreg-practice`。本地 Python + SQLite 服务、原生 ES 模块前端；平时刷题不需要 npm 安装或前端编译。

## 启动

双击 `start.cmd`，或运行：

```powershell
cd D:\project\finreg-practice
.\start.ps1
```

访问 http://127.0.0.1:8765 。关闭服务终端会停止服务，题库和学习记录保留。若服务已在运行，直接打开网址即可。Python 3.10+；启动脚本优先使用 PATH 中的 Python，再尝试本机 Codex 提供的 Python。

首次导入已完成，当前 data 目录包含实际题库。Git 不包含私人题目和学习数据，新克隆源码后须自行提供 `data/bank.json` 或使用页面导入题库。

## 功能

- 学习中心：模块入口、九套真题、覆盖进度、恢复最近练习。
- 题库：模块、小类、试卷、题型、核验状态、关键词、未做/错题/收藏筛选。
- 练习：单选/多选、整卷、随机模块、错题回练、答题卡、暂停、自动保存草稿、笔记收藏、原卷页码、英语材料、本地图题。
- 作答统计：7/30/90天或全部时间，首次/全部作答，练习方式、模块、小类、考点、标签筛选；今日及所选周期指标、每日趋势和可排序分组表。
- 数据：JSON导入预览、去重、题目编辑核验、完整题库导出、SQLite备份、原始业务JSON保留。

## 统计口径

北京时间归日。正确率=答对次数/已判分次数；未作答不计入正确率。多选必须与参考答案集合完全相同。一个练习会话中每题只记一次，重复提交不会重复记分；重新建练习可再次作答。首刷是该题在本地的第一条作答记录，错题按最近一次作答判定。题目多标签时，各标签分组可能重复计数。

计时在页面可见、未暂停、未提交时累计；后台页不计时。时间由本地页面记录，用于学习参考。整卷练习逐题反馈、不强制到时交卷，显示的是正确率而非官方加权分数。编辑参考答案不会重写历史判分，作答记录保存当时答案快照。

## 再抓取粉笔

推荐用 PowerShell 7 执行：

```powershell
.\tools\capture_fenbi.ps1 -Years 2026,2025,2024
```

需要 Node/npm/npx；脚本使用 `@playwright/cli`，首次会下载CLI。浏览器打开后由本人登录，在终端按回车继续。工具只打开试卷、读取标准题目接口，不交白卷；网站可能因此显示对应试卷“未完成”。目前自动选择的是**第一页中可见的地市级真题**，不支持任意年份自动翻页。已经打开的采集会话可用 `-UseOpenSession`。

下载后运行：

```powershell
python scripts/import_fenbi.py
```

再在应用“导入与数据”导入 `data/fenbi-bank.json`。重复ID不新增题目，保留人工编辑，同时更新完整原始字段；未被人工编辑的粉笔题可同步新考点。不将粉笔平台答题统计导入为你的个人作答记录。

六套原PDF的重新导入：安装 `requirements-import.txt` 中依赖，再运行 `python scripts/import_pdfs.py`。这是针对已验收六套资料的解析器，其他版式需先适配和检查。

## 数据保存与备份

- `data/practice.sqlite3`：题库、会话、作答、收藏、笔记、题目原始字段、导入文件整份JSON。
- `data/raw/fenbi`：完整业务响应、材料、章节树、元信息、考点和采集清单，内容摘要区分原始版本。
- `data/fenbi`：采集器最新原始响应，供重建题库。
- `data/assets`、`data/asset-map.json`：原题图片与来源URL映射。
- `data/sources`：六份原卷；`data/bank.json`、`data/fenbi-bank.json` 为可重建数据。
- `data/qa.sqlite3`、`data/qa-*.log`：隔离的验收档案，不是用户成绩。

页面“数据库备份”使用 SQLite backup API，支持服务运行中下载；数据库备份不含图片/PDF文件。完整迁移请停止服务后复制整个 `data` 目录。恢复数据库时停止服务，将备份替换为 `data/practice.sqlite3`（先保留现有数据副本），再启动。

服务只监听127.0.0.1，不提供账号体系或公网访问。
