# 知序 · 金融监管备考工作台

独立项目：`D:\project\finreg-practice`。本地 Python + SQLite 服务、原生 ES 模块前端；平时刷题不需要 npm 安装或前端编译。

## 启动

双击 `start.cmd`，或运行：

```powershell
cd D:\project\finreg-practice
.\start.ps1
```

访问 http://127.0.0.1:8765 。关闭服务终端会停止服务，题库和学习记录保留。若服务已在运行，直接打开网址即可。Python 3.10+；启动脚本优先使用 PATH 中的 Python，再尝试本机 Codex 提供的 Python。

首次导入已完成，当前 data 目录包含实际题库。Git 不包含私人题目和学习数据，新克隆源码后须自行提供 `data/bank.json` 或使用页面导入题库。

## 功能

- 学习中心：优先继续未完成练习；就地选择科目、题量与“只练未做题”；真题按专业科目、行测、申论切换；展示今日表现与最近练习。
- 题库：常用筛选优先、更多条件展开；模块、真题/模拟题、试卷类别、年份、小类、试卷、题型、考点、标签、核验状态、关键词、未做/错题/收藏筛选。筛选与页码保存在网址中，从练习返回可继续浏览，支持清除条件和页码跳转。
- 练习模式：单选点选即判分，答对自动下一题，答错停留看解析；多选选齐后确认，申论保存后对照参考解析。
- 考试模式：可反复修改答案，整卷交卷后统一判分；交卷前不记入学习统计，交卷后答题卡显示对错并可逐题复盘。专项和整卷都可以选择这两种模式。
- 答题：支持错题回练、答题卡、暂停、自动保存草稿、笔记收藏、原卷页码、英语材料和本地图题；手机答题页使用固定底部操作栏，收起全局导航，支持小屏与横屏。非输入框内可用 A–H 选择、Enter 确认/下一题、方向键切题。
- 作答统计：7/30/90天或全部时间，首次/全部作答，练习方式、模块、小类、考点、标签筛选；今日及所选周期指标、每日趋势和可排序分组表。
- 数据：JSON导入预览、就地错误提示、去重、题目编辑核验、完整题库导出、SQLite备份、原始业务JSON保留；来源支持搜索与分页。

界面采用统一的暖白与松绿配色、清晰焦点和阅读字号。桌面侧栏、手机底部导航支持全部功能；答题时手机底部导航让位于答题操作。产品约束见 [PRODUCT.md](PRODUCT.md)，视觉规范见 [DESIGN.md](DESIGN.md)。

## 统计口径

北京时间归日。正确率=答对次数/已判分次数；未作答和申论主观题不计入正确率。多选必须与参考答案集合完全相同。一个练习会话中每题只记一次，重复提交不会重复记分；重新建练习可再次作答。首刷是该题在本地的第一条作答记录，错题按最近一次作答判定。题目多标签时，各标签分组可能重复计数。

计时在页面可见、未暂停、当前题尚未判分时累计；后台页不计时。考试模式交卷前可以反复修改作答，计时继续累计。时间由本地页面记录，用于学习参考。不强制到时交卷，显示的是正确率而非官方加权分数。编辑参考答案不会重写已结束练习的历史判分，作答记录保存当时答案快照。

进度先保存在此浏览器；考试选项或申论文本变化后约1秒同步，切题、暂停、离开页面时同步，持续阅读时每15秒兜底。没有变化或暂停阅读时不持续保存；进入练习只读取一次会话，不轮询会话详情。`/api/session/{id}` 的 POST 是保存位置、草稿与用时，返回轻量确认；`/finish` 在事务中完成交卷，重复请求不重复计分，迟到的保存不会重开已结束的会话。

## 再抓取粉笔

完整接口、字段、Cookie使用方式和断点恢复见 [粉笔接口采集文档](docs/fenbi-api-capture.md)。

```powershell
# 首次打开浏览器，登录后在终端回车；已登录可加 -UseOpenSession
.\tools\capture_fenbi_all.ps1 -UseOpenSession
```

新采集器复用浏览器导出的本地 Cookie，以 GET 接口分页读取四个目录及整卷解析，不提交白卷。按成功文件断点续跑，批量补全两科目的全部已验证字段，下载题图和解析公式，逐卷直接写入 SQLite。已有人工作答、收藏、笔记和人工编辑会保留。登录失效时重新登录导出；`data/fenbi/session.private.json` 含敏感登录态，不要分享。

可分阶段执行：

```powershell
python tools/fenbi_api.py catalog
python tools/fenbi_api.py papers
python tools/fenbi_api.py enrich
python scripts/import_fenbi_api.py
python scripts/audit_fenbi_api.py
```

旧 `capture_fenbi.ps1` 和 `scripts/import_fenbi.py` 保留作三套地市卷历史流程，新一轮采集用上面的入口。

六套原PDF的重新导入：安装 `requirements-import.txt` 中依赖，再运行 `python scripts/import_pdfs.py`。这是针对已验收六套资料的解析器，其他版式需先适配和检查。

## 数据保存与备份

- `data/practice.sqlite3`：题库、会话、作答、收藏、笔记、题目原始字段、导入文件整份JSON。
- `data/fenbi-api/`：全目录原始响应、题目补全批次、逐卷标准JSON和采集/入库/验收报告。
- `data/raw/fenbi-api/`：新增整卷原始数据的内容摘要版本。
- `data/raw/fenbi`：完整业务响应、材料、章节树、元信息、考点和采集清单，内容摘要区分原始版本。
- `data/fenbi`：采集器最新原始响应，供重建题库。
- `data/assets`、`data/asset-map.json`：原题图片与来源URL映射。
- `data/sources`：六份原卷；`data/bank.json`、`data/fenbi-bank.json` 为可重建数据。
- `data/qa.sqlite3`、`data/qa-expanded.sqlite3`、`data/qa-*.log`：隔离的验收档案，不是用户成绩。

页面“数据库备份”使用 SQLite backup API，支持服务运行中下载；数据库备份不含图片/PDF文件。完整迁移请停止服务后复制题库、原题与图片数据；迁移备份不要包含 `session.private.json` 等登录态文件。恢复数据库时停止服务，将备份替换为 `data/practice.sqlite3`（先保留现有数据副本），再启动。

服务只监听127.0.0.1，不提供账号体系或公网访问。

## 开发与验证

```powershell
python -m unittest discover -s tests -v
npm run check
```

单元/集成测试使用临时数据库。界面验收使用 `FINREG_DB=data/qa.sqlite3` 和8766端口，避免测试记录混入实际学习数据。基础回归使用历史九套原题；扩展测试使用合成题验证申论、来源更新保护及过滤。全量库通过 scripts/audit_fenbi_api.py 另行只读审计。

新版界面回归脚本为 `tests/ui_smoke.mjs`，使用独立的8767测试服务和含客观题、申论的隔离题库。运行时要求 `FINREG_UI_QA=1`；默认拒绝8765端口。需要 Playwright 和 Edge，可通过 `PLAYWRIGHT_MODULE` 指定现有 Playwright 包路径，通过 `FINREG_QA_URL` 指定其他隔离服务。脚本会创建练习、作答和笔记，不能指向个人学习档案。详细结果见 [界面改版验收](docs/ui-redesign-validation.md)。

实现分为 `database.py`、`services.py`、`importer.py`、`app.py`，前端按统计/题库/练习/导入拆分。外部工具只参考接口和导出格式，没有整体复制未注明许可证的仓库实现。
